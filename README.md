# hass-meowstar — 喵星公民 (MeowStar) Home Assistant 集成

将 **喵星公民** 智能宠物设备接入 Home Assistant，目前支持：

- **智能猫砂盆**（M1 等 M 系列）
- **智能喂食器**（WS231 / W4 等 W 系列）

非官方社区集成，通过逆向喵星公民 App/H5 云端接口实现（纯 HTTP 轮询，无签名无加密）。

## 功能

### 猫砂盆（M 系列）

| 类型 | 实体 | 说明 |
|---|---|---|
| sensor | 猫砂剩余量 | %，含猫砂重量 kg |
| sensor | 集便仓使用量 | %，≥90% 建议更换集便袋 |
| sensor | 舱内温度 | °C |
| sensor | 今日/昨日/累计清理次数 | 次 |
| sensor | 今日/昨日如厕次数、平均如厕时长 | 次 / 秒 |
| sensor | 最近如厕 | 猫名+时间，含停留时长、体重、排泄物重量、当日次数 |
| sensor | 每只猫的体重 | 按猫识别自动生成（如"福丘 体重""滴滴 体重"） |
| binary_sensor | 猫咪在猫砂盆内 | occupancy |
| binary_sensor | 设备在线 | connectivity |
| button | 一键清理 / 一键抚平 / 深度杀菌 | 触发设备动作 |

### 喂食器（W 系列）

| 类型 | 实体 | 说明 |
|---|---|---|
| sensor | 碗内余粮 | g |
| sensor | 今日出粮 / 今日进食 / 今日进食次数 | g / 次 |
| sensor | 昨日进食 | g |
| sensor | 粮仓温度 / 粮仓湿度 | °C / % |
| sensor | 累计喂食 / 累计花销 / 今日花销 | g / 元 |
| binary_sensor | 设备在线 | connectivity |
| number | 手动喂食克数 | 10–120 g 滑块（步进 10），默认 30 |
| button | 手动喂食 | 按下时按所选克数出粮 |
| button | 碗内余粮清零 | 将碗内重量基准校准为 0，请在确认空碗后使用 |

### Lovelace 卡片（可选，强烈推荐）

`www/meowstar-card.js` 提供两张自定义卡片：

- **喵星公民·猫砂盆**（`meowstar-litter-card`）：猫砂剩余 / 集便仓双环形百分比（红黄蓝反向警示：猫砂越少越红、集便仓越多越红）、舱内温度、累计清理、最近如厕、清理/如厕统计、每只猫的体重与当日情况、一键清理/抚平/杀菌按钮
- **喵星公民·喂食器**（`meowstar-feeder-card`）：碗内余粮（含两步确认的“清零”校准）、进食统计、粮仓温湿度、花销、下粮重量线性滑块（10–120g）+ 快捷档（10/50/90/120g）、手动喂食按钮

> 使用仪表盘时卡片类型需带 `custom:` 前缀：`custom:meowstar-litter-card` / `custom:meowstar-feeder-card`，配置只需选择设备。

## 安装

### HACS（推荐）

1. HACS → 三个点 → 自定义仓库
2. 添加本仓库地址，类别选 **集成**
3. 搜索"MeowStar"安装
4. 重启 Home Assistant

### 手动

将 `custom_components/meowstar/` 复制到 HA 配置目录的 `custom_components/` 下，重启 HA。

### 卡片安装

将 `www/meowstar-card.js` 复制到 HA 配置目录的 `www/` 下，然后在仪表盘资源中注册：

- URL：`/local/meowstar-card.js`
- 类型：`JavaScript 模块`

## 配置

1. 设置 → 设备与服务 → 添加集成，搜索 **MeowStar**（或"喵星公民"）
2. 输入喵星公民 App 的手机号与密码
3. 账号下所有受支持的设备会自动添加

> 提示：同一手机号在 App 与本集成同时登录会互相踢登录态（集成会自动重新登录，无碍运行）；建议使用 App 的"家庭成员/设备共享"功能为本集成创建专用账号，避免影响日常使用。

### 选项

- **刷新间隔**（秒，默认 60，最小 30）

## 支持的设备与兼容性

已在 M1 猫砂盆（Meow10631）与 WS231/W4 喂食器上实测。其他 M/W 系列型号理论上兼容，欢迎提 issue 反馈。

## 已知限制

- 云轮询集成，依赖喵星公民云服务在线；官方接口变更可能导致集成失效
- 灯光、除湿、喂食计划等设置项暂不支持修改（v1 只读 + 核心控制）
- 新增/删除设备需重新加载集成才会出现
- 卡片 JS 有 31 天浏览器缓存，更新后需在资源 URL 加 `?v=` 或硬刷新
